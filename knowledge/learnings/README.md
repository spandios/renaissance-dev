## 📂 구조

### 일별 학습 (Daily)
- 파일명: `YYYY-MM-DD.md`
- 매일 저녁 간단히 기록
- 형식: 자유 (부담 없이)

### 주제별 심화 (Topics)
- 파일명: `spring-aop.md`, `kotlin-coroutines.md` 등
- 깊게 공부한 주제 정리
- 형식: 체계적 (나중에 레퍼런스로 활용)

### 프로젝트 회고 (Retrospectives)
- 파일명: `YYYY-MM-project-name.md`
- 프로젝트 완료 후 회고
- 형식: What Went Well / What Can Improve / Action Items
