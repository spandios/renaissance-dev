# Retrospectives - 프로젝트 회고

_성장은 돌아봄에서 시작된다_

---

## 🔄 회고 원칙

**언제 하나?**
- 프로젝트 완료 후
- 주요 마일스톤 달성 후
- 분기/반기 단위

**왜 하나?**
- 성공 패턴 파악
- 실패에서 배우기
- 다음 프로젝트에 적용

---

## 📂 회고 종류

### 프로젝트 회고
- 파일명: `YYYY-MM-project-name.md`
- Beauty-Sale MVP 완료 후 등

### 주간 회고
- 파일명: `YYYY-WW-weekly.md`
- 매주 일요일 (주간 학습 하이라이트)

### 분기 회고
- 파일명: `YYYY-QX-quarterly.md`
- 분기별 큰 그림 리뷰
