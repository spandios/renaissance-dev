# 🍽️ 점심 지식 Deep Dive: Microsoft and Software Survival

**날짜:** 2026-02-16
**출처:** Stratechery by Ben Thompson
**URL:** https://stratechery.com/2026/microsoft-and-software-survival/

---

## 1. The Big Idea (핵심 관통하기)

AI가 코드 작성 비용을 제로에 수렴시키면서, 소프트웨어 회사의 경쟁 우위는 "코드"에서 "제품 생태계"로 완전히 이동한다 — 그리고 이 전환기에 SaaS 산업은 파이를 키우는 시대에서 **파이를 뺏는 전쟁의 시대**로 진입한다.

## 2. Argument Breakdown (논리 해부)

### 2-1. Microsoft의 위기: ChatGPT 수혜자에서 의문의 대상으로

Ben Thompson은 AI 시대 이후 빅테크가 순번대로 위협받았다고 정리한다:
- **2023년:** Google (검색 위협)
- **2025년 초:** Apple (Siri 실패)
- **2025년 가을:** Meta (Llama 한계)
- **2026년:** Microsoft (Azure 성장 둔화 + CapEx 폭증)

Microsoft는 OpenAI 파트너십 덕에 AI 최대 수혜자로 여겨졌으나, 현실은:
- OpenAI가 Azure RPO의 45%를 차지 → 의존도가 리스크로 전환
- Microsoft 365 Copilot 유료 사용자 1,500만 명이지만 전체 대비 극소수
- 에이전트의 부상이 **per-seat 라이선스 모델** 자체를 위협

### 2-2. AI가 코드를 쓰면, 소프트웨어 회사는 끝인가?

Thompson의 답: **아니다.** 세 가지 이유:
1. **핵심 역량 집중:** 대부분의 기업은 소프트웨어 회사가 아니다. 자체 개발 유인이 낮다.
2. **유지보수의 무한 여정:** 앱 작성은 시작일 뿐. 보안, 신기능, 표준 변경 등 영속적 관리가 필요하다.
3. **코드 ≠ 제품:** 지원, 컴플라이언스, 통합 — 코드 이상의 가치가 소프트웨어 제품의 본질이다.

**핵심 반전:** 소프트웨어 회사는 AI의 피해자가 아니라 **최대 수혜자**다. 더 빠르고 효율적으로 코드를 생산할 수 있기 때문이다.

### 2-3. 인터넷과 출판업의 비유 — 진짜 위험

여기서 Thompson의 진짜 날카로운 통찰이 나온다. 인터넷이 출판사에게 했던 것을 AI가 소프트웨어에 할 수 있다:

- 인터넷 → 배포 비용 제로 → 개별 출판사에겐 좋지만, 집단적으론 재앙
- AI → 코드 비용 제로 수렴 → 개별 회사엔 좋지만, SaaS 생태계 전체에겐 위기

**결론:** SaaS의 깔끔하게 사일로화된 생태계가 붕괴한다. 지난 10년은 "파이 키우기"였다면, 앞으로 10년은 **"파이 쟁탈전"**이다. 모든 SaaS 회사가 인접 영역을 공격하게 되고, 모델 제공자(OpenAI, Anthropic 등)가 **무기상**이 된다.

### 2-4. 에이전트와 Work IQ

Microsoft의 대응: **Work IQ** — Active Directory 기반의 조직 내 정체성·권한·아티팩트를 이해하는 에이전트 레이어. 이것이 Microsoft의 진짜 해자(moat)다. 코드가 아니라 **조직의 컨텍스트**를 소유하고 있기 때문이다.

## 3. Why It Matters (왜 중요한가)

**2026년의 전환점:**
- AI CapEx가 천문학적으로 증가하는 가운데, 투자자들은 "이게 정말 돈이 되는가?"를 묻기 시작했다.
- SaaS 기업의 재평가(re-rating)가 진행 중이며, 이는 구조적 변화다.
- 소프트웨어 산업의 경쟁 구도가 근본적으로 바뀌고 있다: **수직적 전문화 → 수평적 영역 확장**.

**개발자에게 가장 중요한 시그널:**
코드의 가치가 하락하고 있다. 하지만 **제품을 만드는 능력**, **시스템을 설계하는 능력**, **비즈니스 문맥을 이해하는 능력**의 가치는 오히려 급등한다.

## 4. 💼 For Engineers (개발자에게)

### 즉각 실행 가능한 행동 지침:

1. **"코드 장인"에서 "제품 아키텍트"로 포지셔닝 전환**
   - AI가 코드를 쓰는 시대에, 차별화는 "무엇을 만들 것인가"에 대한 판단력이다.
   - 비즈니스 로직, 사용자 경험, 시스템 간 통합에 더 많은 시간을 투자하라.

2. **인접 영역 공격을 준비하라**
   - SaaS 전쟁이 격화되면, 당신의 회사도 인접 영역으로 확장해야 한다.
   - 경쟁사 제품의 핵심 기능을 빠르게 복제할 수 있는 AI 활용 파이프라인을 구축하라.

3. **"에이전트 퍼스트" 사고를 시작하라**
   - 앞으로의 소프트웨어는 사람만 쓰는 게 아니라 **에이전트도 쓴다**.
   - API 설계, 권한 모델, 데이터 접근 패턴을 에이전트 친화적으로 재설계하라.

4. **모델은 도구, 컨텍스트가 해자**
   - Microsoft의 Work IQ 전략이 보여주듯, 진짜 가치는 조직의 컨텍스트를 이해하는 것.
   - beauty-sale 같은 프로젝트에서도: 가격 데이터 자체보다 **사용자의 구매 컨텍스트**를 깊이 이해하는 것이 경쟁력.
